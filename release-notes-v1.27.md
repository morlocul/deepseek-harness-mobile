## Harness v1.27 — DeepSeek Harness on your phone

Native Android chat client for **your own** DeepSeek Harness over **Tailscale**.

### What's new
- **Chat** — streaming, live **reasoning** ("thinking…" indicator + deep-think content), markdown (tables, code blocks).
- **Model switching** — top button or `/model`; vision models read attached images.
- **Images** — attach in chat; chat images render inline.
- **Workspace** — browse the project folder on the PC.
- **Shared files** — download/preview files (PDF/DOCX/video/images) over Tailscale from a `shared` folder.
- **QR connect** — scan a per-user QR to pre-fill your address (deep link `harness://open?url=…`).
- **Themes** — light / dark / system.
- **Updates** — in-app (server) + "Check for updates (GitHub)".
- **Copy** — long-press a message to copy its text.
- **Cleaner navigation** — Chats · Workspace · Settings (icons).

### Install
Download `app-release.apk` from the Assets below, open it on your phone, allow *install from unknown sources*.

> Each user connects to their **own** DSH instance through their **own** tailnet. See the README for setup.
